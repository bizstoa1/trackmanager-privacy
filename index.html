3. 갤러리에 저장되는 사진 사본

저장한 사진은 앱 전용 공간 외에 휴대전화의 Pictures/TrackMaster/ 폴더에도 한 부 복사됩니다. 이 폴더의 사진은 다른 갤러리 앱 등에서 보일 수 있으며 트랙매니저를 삭제해도 남습니다. 앱에서 결함이나 사진을 삭제한 경우에도 갤러리 사본은 별도로 확인하여 삭제해 주세요. 합성된 캡션 워터마크는 사진의 일부이므로 사본을 공유할 때 함께 전달됩니다.

앱은 현장 기록을 자동 업로드하거나 동기화하지 않습니다. 데이터가 외부로 전달되는 것은 사용자가 직접 내보내기·공유를 실행하고 대상 앱 또는 저장 위치를 선택한 경우입니다. 공유 전 사진의 캡션과 파일에 포함된 기록을 확인해 주세요.

개발자는 앱 내 데이터를 제3자에게 제공하거나 개인정보 처리 업무를 위탁하지 않습니다. 사용자가 선택한 공유 대상 앱·서비스의 이후 데이터 처리는 해당 제공자의 방침에 따릅니다. 이는 개발자의 자동 제공 또는 처리 위탁이 아닙니다. 갤러리나 저장 위치에 대한 다른 앱·기기 서비스의 접근 및 사용자가 설정한 동기화도 해당 앱·서비스의 설정과 방침을 확인해 주세요.

5. 보관 기간과 삭제 방법

개발자 서버에 보관하는 데이터나 별도의 서버 보관 기간은 없습니다. 기기의 기록과 설정은 사용자가 삭제하거나 앱 데이터를 지울 때까지 기기에 보관됩니다.

  • 개별 기록·사진: 앱 내 삭제 기능을 이용합니다. 실행취소 가능한 조작은 앱에서 되돌릴 수 있으므로, 앱 전용 데이터 전체를 제거하려면 아래 방법을 이용해 주세요.
  • 앱 전용 데이터 전체: Android 설정에서 트랙매니저의 저장공간에 있는 앱 데이터 삭제 기능을 이용하거나 앱을 제거합니다. 앱 제거 시 기기의 앱 전용 데이터베이스·사진·설정이 삭제됩니다.
  • 갤러리 사본: 갤러리 또는 파일 앱에서 Pictures/TrackMaster/ 폴더의 사진을 직접 삭제합니다. 해당 앱의 휴지통에 남은 경우 영구 삭제도 진행해 주세요.
  • 내보내기·백업·공유 사본: 사용자가 저장한 xlsx·ZIP·CSV 등과 공유 대상에 전달된 사본은 앱 제거로 삭제되지 않습니다. 각 저장 위치 또는 수신 서비스에서 별도로 삭제해 주세요.

개발자는 기기의 데이터를 대신 조회·수정·삭제할 수 없습니다. 기록 열람과 수정은 앱에서, 삭제는 위 방법으로 직접 할 수 있습니다. 기기 잠금과 파일 공유 대상을 관리하고 필요한 자료는 직접 백업해 주세요.
